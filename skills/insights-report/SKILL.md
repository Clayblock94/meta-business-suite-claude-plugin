# Insights report

First apply the rules of the `meta-business-suite` skill. Report only numbers actually read on screen.

## Procedure

1. Ask (or infer) the period: last 7, 28 or 90 days, or a range tied to an event (e.g. the weeks around an event).
2. In Insights, read for Facebook and Instagram separately: reach, views, interactions, profile/page visits, link clicks, new followers, and the best-performing content.
3. For each metric note the value and the change from the previous period, if Meta shows it.
4. If some metrics are not visible or the account has too little data, say so: do not estimate or round up with invented values.
5. Write the report in the user's language: 3-4 line summary, table of key metrics, top 3 content items with format and likely reason (labelled as a hypothesis), 2-3 suggested actions.
6. If the report is meant to be kept or shared, offer to turn it into a document; otherwise deliver it in the chat.

## Notes

- Do not compare with third-party profiles using non-public data.
